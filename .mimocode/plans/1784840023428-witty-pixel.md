# Plan: Add Selectable Aggregation for KPI Series Data in Widget Inspector

## Problem

When a KPI has series data (`mapped_rows`), the displayed value is **always the average** of all row values (hardcoded in `KpiResultComputer.php:84`). The user needs the ability to choose the aggregation method (Sum, Count, Average, Min, Max, etc.) per-widget from the inspector panel.

## Decisions (confirmed by user)

- **Scope**: Both standalone widgets (KPI Card, Gauge, Donut) AND Table Grid cells
- **Default**: Uses backend's pre-computed `scalar_value` (currently always average). User must explicitly select a function to override.

## Approach: Frontend-Only Client-Side Re-Aggregation

Add a `valueAggregation` config field to each widget and table cell. When the KPI has `mapped_rows`, the frontend re-computes the displayed value from the series using the selected function instead of using the pre-computed `scalar_value`.

### 2. `resources/js/components/builder/widgets/shared.tsx`

**a)** Add an `aggregateSeries()` helper function that takes an array of `{x, v}` series values and an aggregation function name, returns a single number:

```typescript
export type AggregationFn = "default" | "sum" | "average" | "min" | "max" | "count" | "first" | "latest";

export function aggregateSeries(values: number[], fn: AggregationFn): number | null {
  if (values.length === 0) return null;
  switch (fn) {
    case "sum": return values.reduce((a, b) => a + b, 0);
    case "average": return values.reduce((a, b) => a + b, 0) / values.length;
    case "min": return Math.min(...values);
    case "max": return Math.max(...values);
    case "count": return values.length;
    case "first": return values[0];
    case "latest": return values[values.length - 1];
    default: return null; // null = use scalar_value from backend
  }
}
```

**b)** Modify `resolveKpiValue()` to accept an optional aggregation parameter. When `aggregation` is set and is not "default", and `mapped_rows` exists, compute from series instead of using `scalar_value`:

```typescript
export function resolveKpiValue(
  c: WidgetConfig,
  kpiData?: KpiDataMap,
): { value: number; hasData: boolean; status: string } {
  const kpiResult = c.kpiCode ? kpiData?.get(c.kpiCode) : undefined;
  const hasData = !!(kpiResult && kpiResult.scalar_value !== null);
  const status = kpiResult?.status ?? "grey";

  // If aggregation is specified and series data exists, re-compute from series
  const agg = c.valueAggregation;
  if (agg && agg !== "default" && kpiResult?.mapped_rows?.length) {
    const joinKey = Object.keys(kpiResult.mapped_rows[0]).find((k) => k !== "value") ?? "x";
    const values = kpiResult.mapped_rows
      .map((row) => Number(row.value ?? 0))
      .filter((v) => !isNaN(v));
    const computed = aggregateSeries(values, agg);
    if (computed !== null) return { value: computed, hasData: true, status };
  }

  const value = hasData ? kpiResult!.scalar_value! : 0;
  return { value, hasData, status };
}
```
